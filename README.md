# 关山阅 · 网站改版 URL 映射检查

检查旧网址与新网址映射中的遗漏、冲突、链路和循环。适用于 Google SEO 改版迁移前验收，不直接修改服务器。

**品牌：关山阅（SEOGuan）**  
**运营主体：广州知乎网络科技有限公司**  
**官网：[www.seoguan.com](https://www.seoguan.com)**  
**版本：1.0.0 · 许可证：[MIT](LICENSE)**  
**业务环节：03 网站检查**

## 输入与输出

输入：mapping.csv列old_url,new_url；可选旧站清单old_urls.txt、目标状态与canonical的抓取记录。

输出：redirect-audit.json：issues与counts；迁移复核表保留old_url,new_url,reason,evidence,status。

## 工作步骤

1. 将旧站清单与映射逐项比对；路径和查询参数保留，不把不同产品合并。
2. 运行 scripts/check_mapping.py，区分冲突映射、重复行、自跳转、链路、循环和旧页遗漏。
3. 多个旧页归同一个新页是复核项，不一律判错；检查新页是否真的承接原意图。
4. 目标URL存在于表不证明目标200。只有实际响应证据才能确认跳转状态和最终页。
5. 给出待修表及上线后验证清单；需要服务器规则时另行生成草稿，不自动部署。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-redirect-mapper`。支持 `$技能名` 的宿主可使用下方示例。

依赖：Python 3.10 或以上，脚本仅使用标准库。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。

本工具附带本地脚本，请先阅读[脚本用法与样例](references/script-usage.md)。
